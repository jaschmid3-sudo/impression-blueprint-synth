# 1-Hour Impression Blueprint & Audio Synthesizer

An interactive Web Audio API application combined with a digital marketing guide. This project synthesizes a live blues audio track featuring the classic **Bo Diddley rhythm**, **C-E-G boogie-woogie bass**, and a **blues harmonica melody**, alongside a strategic guide to hitting 100 impressions online within one hour.

## Features
- **Web Audio API Synth Engine:** Plays synthesized drums, bass, and reed-harmonica entirely in pure JavaScript (no external audio assets required).
- **Interactive Dashboard:** Displays strategy cards covering fast-track channels and high-impression keywords.
- **LinkedIn Post Copy Generator:** Built-in copy button to instantly export pre-formatted post copy for social sharing.
